Frequently Asked Questions

1. Connecting to your Immich Server

Lymic requires an existing self-hosted Immich instance. You will need:

  • Server URL: The full HTTPS address of your Immich server (e.g. https://immich.example.com). Unencrypted HTTP is permitted only for local loopback addresses (127.0.0.1 or localhost) with explicit confirmation.
  • API Key: Generated in your Immich web interface under Account Settings → API Keys.
  • Cloudflare Access (optional): If your Immich server is protected behind Cloudflare Zero Trust, provide your Service Token Client ID and Client Secret in the Advanced Options section.

2. Watched Folders and Removable Media

Add one or more local folders to synchronize to your Immich server.

  • Target Albums: You can assign a specific Watched Folder to an Immich album. Both newly uploaded and already existing matching media will be added to that album.
  • Removable Drives: Removable drives (such as SD cards or external hard drives) can be bound to watched folders. If the drive is disconnected, the folder configuration is preserved and synchronization resumes automatically when reconnected.
  • File Access Restrictions: Ensure the Lymic desktop app has permission to read files within your selected folders.

3. Updates and Distribution Channels

Lymic is distributed via two official Windows channels:

  • Microsoft Store (MSIX): Installed and kept updated automatically through the Windows Microsoft Store. In-app updater checks are intentionally disabled for Store packages to avoid conflicting update mechanisms.
  • GitHub Releases (NSIS): Self-contained Windows installer that receives signed in-app updates via GitHub releases.
